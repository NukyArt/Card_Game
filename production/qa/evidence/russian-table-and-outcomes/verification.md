# Русский стол и тестовые исходы — 2026-11-14

## Запуск
Обычная партия (прежние данные/баланс):
```bash
./gradlew :desktop:run
```
Тест победы:
```bash
./gradlew :desktop:run --args="--qa=victory"
```
Тест поражения:
```bash
./gradlew :desktop:run --args="--qa=defeat"
```
В каждом случае: «Создать лобби» → «Играть с ботами». QA-профиль явно помечен в меню и на столе. «Новая партия» сохраняет профиль текущего запуска; для обычной игры перезапустить без --qa.

### Победа
1. На рынке нажать «Завершить ход» один раз и дождаться производства / хода Игрока.
2. Выбрать Казначея → «Активировать». Кнопкой «Сумма +» выставить 4 → «Проекту: 4 золота».
3. Последовательно выбрать и активировать Ферму, Лесопилку, Башню ученика. Проект показывает 4/5 этапов.
4. Выбрать свою основу → «Внести основу с улучшениями». Настоящий исход VICTORY после пятого этапа.

### Поражение
1. На рынке нажать «Завершить ход» один раз, дождаться ботов.
2. В своём производстве нажать «Завершить ход» один раз.
3. Дождаться ботов и депозита. После единственного раунда наступает DEFEAT.
4. На результате «Главное меню» должно возвращать сразу, без подтверждения потери прогресса.

## Изменения
Presentation использует русские названия карт/этапов из имеющихся данных, отдельный русско-английский словарь с контекстом, форматирование enum/ресурсов/цен и команд. Кириллический Noto Sans создаётся общим UiFonts, но шрифт принадлежит конкретному экрану. Для неизвестных отказов показывается «Действие недоступно», оригинал логируется; каталог содержит основные известные отказы, не является гарантией перевода каждого возможного технического исключения.

QA fixtures отдельные: пять облегчённых этапов победы; один раунд и недостижимые требования поражения. Domain/application, обычные данные и баланс не изменялись.
